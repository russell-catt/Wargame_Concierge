## Exact list — 1000 / 1000

Captain **80** + Honour Vehement **15** + Tacticals **140** + Devastators **120** + shooting Terminators **160** + Terminator Chaplain **75** + Assault Terminators **155** + one thunder hammer **5** + Techmarine **55** + Artificer Armour **20** + Whirlwind **175** = **1000**.

**Deployment lock:** shooting Terminators start on the field. Chaplain + Assault Terminators Deep Strike. Techmarine remains independent beside the Whirlwind.

**Proxy lock:** Chaplain's modeled lightning claw represents the shield option — use the current **relic shield** rules (owner shorthand: Storm Shield), raising him to W6 and replacing his storm bolter. Assault Terminators use one hammer/shield profile and four twin-claw profiles; agree which physical model is which before deployment.

**Force Disposition:** **PRIORITY ASSETS**.
