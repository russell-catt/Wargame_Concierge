# Starter list - 500 points (Matched)

> **FORCE DISPOSITION — write on the list before you deploy**
> **Priority Assets** · MFM: `GLADIUS TASK FORCE - 3DP - PRIORITY ASSETS`
> How matching works: [`../../setup/Chapter_Approved_Force_Dispositions.md`](../../setup/Chapter_Approved_Force_Dispositions.md)

> **Matched play — no Legends.** Costed from Munitorum Field Manual (Marines) only. For Bike Squad, Attack Bike, and Astartes Servitors see the Casual twin.

500 points is the first size that feels like a real game: a character worth protecting, a gun line, and enough units that [Combat Doctrines](Gladius_Task_Force.md) matter.

**Blood Ravens paint; Codex Space Marines; Gladius.** No Deathwatch in these lists.

**Points:** Munitorum Field Manual (Marines) v1.2.

---

## Owned path BR — Firstborn core: 500 / 500 exactly

Continues **BR-2** ideas from [`Starter_250_Matched.md`](Starter_250_Matched.md) and adds the Devastators and a Terminator brick.

| Unit | Models | MFM Marines v1.2 | Ownership | Notes |
|------|--------|------------------|-----------|-------|
| **Captain** (Leader) | 1 | **80** | **Owned** | Attach to Tactical Squad |
| **Tactical Squad** | 10 | **140** | **Owned** | Midboard OC — Tac1 includes a **flamer** |
| **Devastator Squad** | 5 | **120** | **Owned** | HB / multi-melta / plasma cannon / lascannon / meltagun — optional: borrow 5 bolter Tacticals → **10 models / 200 pts** (shrink a Tactical) |
| **Terminator Squad** | 5 | **160** | **Owned** | Armour brick |
| | | **500** | | |

**How to attach:** Captain leads the **Tactical Squad**. Terminators run without a character at this size (save the Chaplain for 750).

**Optional rebuild:** move five bolter Tactical Marines into the Devastators for a **10-model Devastator Squad (200 pts)**. Drop or shrink a Tactical accordingly and re-total the list (this 500 path as written keeps Devs at 5).

**Lesson:** concentrate Oath and Devastator Doctrine on the unit that needs to move and still shoot, or on the Devastators if they Advanced into a lane.
