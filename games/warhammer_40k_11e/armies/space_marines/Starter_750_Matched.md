# Starter list - 750 points (Matched)

> **FORCE DISPOSITION — write on the list before you deploy**
> **Priority Assets** · MFM: `GLADIUS TASK FORCE - 3DP - PRIORITY ASSETS`
> How matching works: [`../../setup/Chapter_Approved_Force_Dispositions.md`](../../setup/Chapter_Approved_Force_Dispositions.md)

> **Matched play — no Legends.** Costed from Munitorum Field Manual (Marines) only. For Bike Squad, Attack Bike, and Astartes Servitors see the Casual twin.

750 is where the Blood Ravens shelf starts looking like an army: Captain buffing the midboard, Chaplain in the Terminator brick, and a second Terminator unit so you are not one-brick dependent.

**Paint / rules:** Blood Ravens paint; **Codex Space Marines**; [Gladius Task Force](Gladius_Task_Force.md). **Deathwatch stays out.**

**Points:** Munitorum Field Manual (Marines) v1.2.

---

## Owned path BR — double Terminators: 750 / 750 exactly

Continues the owned **500** list from [`Starter_500_Matched.md`](Starter_500_Matched.md): keep Captain + Tacticals + Devastators + Terminator Squad, then add the Chaplain and the second Terminator Squad.

| Unit | Models | MFM Marines v1.2 | Ownership | New vs 500? |
|------|--------|------------------|-----------|-------------|
| **Captain** (Leader) | 1 | **80** | **Owned** | from 500 |
| **- The Honour Vehement** | - | **15** | n/a | **new** |
| **Chaplain in Terminator Armour** (Leader) | 1 | **75** | **Owned** | **new** |
| **Tactical Squad** | 10 | **140** | **Owned** | from 500 — flamer in Tac1 |
| **Devastator Squad** | 5 | **120** | **Owned** | from 500 — HB / MM / PC / LC / meltagun |
| **Terminator Squad** | 5 | **160** | **Owned** | from 500 — Chaplain attaches here |
| **Terminator Squad** | 5 | **160** | **Owned** | **new** |
| | | **750** | | |

**How to attach**

- **Captain** (with Honour Vehement) → **Tactical Squad**
- **Chaplain in Terminator Armour** → first **Terminator Squad**

**Model note:** Terminator Chaplain’s power claw = **Storm Shield** in game (owner).

**Spare models not in this list:** second Tactical (fill with spares later), Assault Terminators, Whirlwind, Techmarine, Lieutenant with Combi-weapon — see [`Starter_1000_Matched.md`](Starter_1000_Matched.md).

## What the jump from 500 to 750 teaches

| Capability | How this list provides it |
|------------|---------------------------|
| Two Leaders | Captain on OC; Chaplain on the brick |
| Enhancement habit | Honour Vehement on the Captain |
| Redundancy | Two Terminator units — losing one brick is not game over |
| Doctrine pressure | Six units — spending Assault Doctrine on the wrong brick hurts |
