# Starter list - 1000 points

1000 points is a full learning battle: midboard OC, two Terminator threats, a gun line, indirect fire, and a Techmarine babysitting the Whirlwind.

**Paint / rules:** Blood Ravens paint; **Codex Space Marines**; [Gladius Task Force](Gladius_Task_Force.md). **Deathwatch stays out.** Bikes stay **Legends** (friendly only).

**Points:** Munitorum Field Manual (Marines) v1.2.

---

## Owned path BR — artillery + armour: 980 / 1000

Continues [`Starter_750.md`](Starter_750.md): keep the 750 core, drop Honour Vehement if you need room (this build keeps it off and spends the points on Techmarine + Whirlwind), or keep enhancement and trim — this table is the clean owned fit.

| Unit | Models | MFM Marines v1.2 | Ownership | Notes |
|------|--------|------------------|-----------|-------|
| **Captain** (Leader) | 1 | **80** | **Owned** | → Tactical Squad |
| **Chaplain in Terminator Armour** (Leader) | 1 | **75** | **Owned** | → Terminator Squad; claw = **Storm Shield** in game |
| **Techmarine** (Leader) | 1 | **55** | **Owned** | → Devastator Squad (or babysit Whirlwind locally) |
| **Tactical Squad** | 10 | **140** | **Owned** | |
| **Devastator Squad** | 5 | **120** | **Owned** | |
| **Terminator Squad** | 5 | **160** | **Owned** | Chaplain attaches |
| **Terminator Squad** | 5 | **160** | **Owned** | Second brick |
| **Whirlwind** | 1 | **175** | **Owned** | 1st Whirlwind cost; hatch figure unfinished on model |
| | | **965** | | |

Add **The Honour Vehement (15)** on the Captain → **980 / 1000**. Twenty points spare.

**Servitors:** four painted bodies sit with the Techmarine photo. Confirm whether current rules still use a separate Servitor datasheet before costing them; until then field the **Techmarine** alone.

## Owned variant — second Tactical instead of Whirlwind: 965 / 1000

| **Terminator Squad** | 5 | **160** | **Owned** |
