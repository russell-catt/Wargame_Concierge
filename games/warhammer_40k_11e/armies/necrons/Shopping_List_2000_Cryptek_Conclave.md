# Shopping list — ~2,000 pts — Cryptek Conclave

> **Baseline today:** [`Army_List_1000_V1_Doomstalker_Conclave.md`](Army_List_1000_V1_Doomstalker_Conclave.md) ≈ **945 / 1,000** (owned + Hierotek proxies).  
> **Target:** fill ~**1,000 more** without quitting Conclave.  
> **FORCE DISPOSITION (when you write a 2k list):** **Priority Assets** · `CRYPTEK CONCLAVE - 2DP - PRIORITY ASSETS`

**Owner locks (2026-10-22):** Nightbringer is a keeper (40K + KT Nemesis / Joint Ops). Second Doomstalker is wanted. Extra Warriors / Scarabs are superfluous (flip ~$25 if a box dumps them). Nekrosor Ammentar is shelf-only — do not shop for him.
