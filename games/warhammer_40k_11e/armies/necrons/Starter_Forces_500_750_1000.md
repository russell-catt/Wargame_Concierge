# Necron starter forces - 500 / 750 / 1,000 (v1.1)

Rebuilt on **current ownership** (Tomb World + Hierotek photo ID + sprue). Prior dual-path draft that treated Hierotek as un-IDed is **superseded**.

| Version | Rule |
|---------|------|
| **V1 - no more purchases** | Only models already owned (including sprue once built). **Hierotek Circle proxies allowed** for kitchen-table / learning games (opponent OK). |
| **V2 - finished with purchases** | Keep every owned kit that earns its keep, then buy the fewest new kits for a strong **Canoptek Court** list. |

**Detachment default for V2:** [`Canoptek_Court.md`](Canoptek_Court.md). V1 plays as Court or Conclave; Conclave gets more from the Hierotek Cryptek + Immortal brick.
