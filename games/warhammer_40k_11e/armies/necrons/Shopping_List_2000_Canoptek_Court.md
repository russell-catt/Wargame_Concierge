# Shopping list — ~2,000 pts — Canoptek Court

> **Baseline today:** Tomb World + Hierotek + primed Warriors/Scarabs/Immortals + **1× Doomstalker** (see [`Owned_Models_Inventory.md`](Owned_Models_Inventory.md)).  
> **Detachment rule:** Power Matrix — rewards **Cryptek** and **Canoptek** units on / near objectives. Warriors / Immortals are screens only (no Matrix buff).  
> **FORCE DISPOSITION (when you write a 2k list):** check MFM for Canoptek Court DP / Primary match — write it before deploy.

**Owner locks (2026-10-22):** Second Doomstalker wanted. Nightbringer is a keeper (solo hammer + KT). Extra Warriors / Scarabs superfluous. Ammentar = shelf — skip.
