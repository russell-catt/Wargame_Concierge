# Necrons — 11th Edition

**Player:** Parent (Russell)

Ancient undying machines waking from tomb worlds. Necrons excel at **reanimation**, **methodical shooting**, and **Canoptek construct** synergies. Two expansion paths are documented in the collection blueprint: **Canoptek Court** and **Cryptek Conclave**.
