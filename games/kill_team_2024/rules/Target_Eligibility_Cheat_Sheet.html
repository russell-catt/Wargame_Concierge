After selected (sequence, not eligibility):

Obscured? Heavy intervening; 1" ignores only that part of Heavy, not the whole feature · discard 1 success; crits → normal SEQUENCE p.53
Saturate weapon? Defender cannot retain cover saves SEQUENCE p.111
Cover save (Engage in cover): collect three defence dice; retain one normal success without rolling; roll the remainder SEQUENCE p.43

Modifiers when selecting

  • Seek / Seek Light — Conceal cannot use terrain (Light only for Seek Light) for cover; save may remain. On Vantage you may elect Seek only (skip Vantage improved save) p.111, update log p.5
  • Vantage shooter — Vantage is also Light. Conceal targets ≥2" lower cannot use Light for cover; improved cover save. Accurate 1/2 vs Engage ≥2"/≥4" lower is SEQUENCE p.60
  • Blast / Torrent — secondaries valid regardless of Conceal; not selected. Cover/obscured (and Vantage improved save) copy the primary p.111, update log p.2 / p.4–5
  • Silent — Shoot with Conceal order using this weapon; does not lift in-enemy 1" control range p.111
  • Heavy — cannot use in an activation or counteraction in which it moved (and vice versa); Heavy (x only); does not prevent Guard update log p.2, lite p.3

Intervening / lines

  • Shooter chooses targeting-line origin on own base; 1mm lines to facing parts of target base; markers treated as a base p.51
  • Blocking gaps: visibility cannot pass; counts intervening (gaps, not physical terrain) p.59
  • Exposed: never intervening for cover/obscured p.61
  • Cover + obscured same feature: defender picks one update log p.2
  • “Connected” Heavy for Vantage obscured = any part of the same terrain feature p.60, update log p.5

1" control range

  • Visible + within 1" · mutual between operatives p.46
