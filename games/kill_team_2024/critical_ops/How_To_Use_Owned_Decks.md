# Critical Ops — how to use the decks you own

**Owned:** 2024 deck + 2025 deck (physical + local printables). Pointers: [`raw/pointers/kill_team_2024_critical_ops.md`](../../../raw/pointers/kill_team_2024_critical_ops.md).

## One-pager

1. Pick **one** deck year for the evening.
2. Follow that deck’s setup sheet for card count and reveal timing.
3. Turning points / activations still follow Core Rules — cards change scoring, not the Firefight loop.
4. Do not mix Crit Ops with Joint Ops frameworks on the first learning night.
5. Card text SoT = **cards in hand**, not this file.

See also [`README.md`](README.md).
