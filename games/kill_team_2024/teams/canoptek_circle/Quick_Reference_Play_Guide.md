# CANOPTEK CIRCLE — TABLE REFERENCE | Page 1 of 2

## YOUR TURNING POINT, IN ORDER

| # | Step | Do this |
|---|------|---------|
| 1 | **Initiative** | Roll off (or use last turning point's loser-picks-first rule) to see who chooses initiative |
| 2 | **Strategy phase** | Gain CP. Ready operatives. **Move your Obelisk Nodes** (Strategic Gambit, T1 place / T2+ up to 3" each). Play any Strategy Ploys |
| 3 | **Firefight phase** | Players alternate activating one ready operative at a time — move, shoot, fight, or take actions, spending APL as you go |
| 4 | **Counteract** | If you run out of ready operatives before your opponent, an Engage-order operative can counteract for 1AP, once each |
| 5 | **End of turning point** | Score Crit Op / Kill Op / Tac Op as revealed; check markers |

**Actions cost AP from an operative's APL.** No separate movement/shooting/fight phases — everything happens inside the activation.

---

## OBELISK NODE MATRIX — YOUR TEAM RULE

| Step | Habit |
|------|-------|
| **T1 Strategic Gambit** | Place all 3 nodes wholly in your territory |
| **T2+ Strategic Gambit** | Move each node up to 3" horizontally |
| **Node alone** | Controls any uncontested marker within 1" — treated as a friendly operative |
| **2 nodes within 6"** | Forms a Matrix (the space between + both markers, ignoring height) |
| **All 3 within 6" of each other** | One larger combined Matrix |
| **Inside the Matrix** | Friendly Canoptek Circle operative gets an Accurate boost + **+1 APL (max 3)** |

**Do:** plan the triangle for the whole game, not just T1. **Don't:** treat nodes as fast — 3"/turn is a crawl.

## PLOYS AT A GLANCE — gist only, verify full text before use

| Strategy | Gist | Firefight | Gist |
|----------|------|-----------|------|
| Hypershielding | Re-roll a defence die in/near the Matrix | Nodal Response | Swap/re-trigger a Strategy Ploy mid-activation |
| Cryptogravitic Repulsion | First enemy move into the Matrix costs extra | Animate Obelisk Nodes | Move nodes up to 6" combined, off-cycle |
| Transdynamic Amplification | Shooting boost while Matrix is involved | Shield Flare | Shrug a point of damage near the Matrix |
| Souldrain | Weakens enemy melee damage in/near the Matrix | Sacrificial Thrall | Redirect a hit/attack off the Geomancer |

---

## COMBAT SEQUENCE

1. **Roll attack dice** — successes on APL-independent target numbers per weapon; retain up to your **Lethal**/**Ceaseless**/**Accurate** allowances.
2. **Roll defence dice** — defender rolls to save; Matrix-linked re-rolls apply if relevant.
3. **Compare and resolve** — normal vs. critical successes cancel per the core sequence; apply Dmg for unsaved successes.
4. **Injured check** — an operative below half starting wounds is Injured: Move −2", weapons' Hit worsened by 1.

## DO / DON'T

| | |
|---|---|
| **DO** commit to a node triangle before you deploy operatives | **DON'T** expect to relocate the Matrix quickly — 3"/turn per node |
| **DO** let a node babysit an objective so an operative is free elsewhere | **DON'T** forget nodes are contested away if an enemy operative is also within 1" |
| **DO** route fights through the Matrix whenever the map allows it | **DON'T** stand next to the Matrix expecting the buff — you must be inside it |
| **DO** hold Animate Obelisk Nodes / Nodal Response in reserve for a reactive turn | **DON'T** burn both ploys early just because you can |
| **DO** treat Macrocyte Warriors as expendable — that's their job | **DON'T** panic-protect them at the cost of tempo elsewhere |
