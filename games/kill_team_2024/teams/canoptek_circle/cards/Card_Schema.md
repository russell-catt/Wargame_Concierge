# Card Schema — Canoptek Circle (printable datacards)

**Five operative-type cards** (not one per model): Geomancer, Tomb Crawler, Macrocyte Accelerator, Macrocyte Reanimator, Macrocyte Warrior.

**Layout:** Inspired by [u/Armagonix](https://www.reddit.com/user/Armagonix/) `kt24_unit_datacards_template.pdf` — header name + stat bar, weapons table, rules block, footer cite.

**Print:** Open each `.html` in browser → print. Target ~90×63mm per card (adjust scale in print dialog).
