## What belongs here

| Kind | Example |
|------|---------|
| Filed query answers | A good answer that would otherwise vanish into chat history |
| Matchup notes | Necrons into Space Marines: what each side is trying to do |
| List comparisons | Two builds from the same owned model pool, side by side |
| Gap analyses | What the collection cannot currently do |
| Game reports | What actually happened in a game, and what to change next time |

## The compounding rule

After answering a question, ask: *"Should I file this?"* If the answer took real synthesis across several pages, the answer is yes. An analysis that stays in chat has to be re-derived next time - which is exactly what this KB exists to avoid.

## Cite your inputs

Analysis pages are built **from other KB pages**, so link every page you drew on and carry the weakest input's confidence forward. An analysis resting on `unverified` unit pages is itself `unverified`, however well reasoned.

Game reports are authoritative for *what happened* and never for *what the rule says*.
