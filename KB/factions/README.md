# KB/factions/

One page per **army**. The entry point for everything about a faction - a reader should be able to start here and reach every detachment and unit page for that army.

**Type:** `faction` · **Filenames:** lowercase `snake_case` · **Schema:** [`AGENTS.md`](../../AGENTS.md) Sec 4, Sec 6

## Suggested sections

| Section | Content |
|---------|---------|
| Identity | What the army is and how it wants to win |
| Army rule | The faction-wide mechanic, in teaching paraphrase |
| Playstyle | Strengths, weaknesses, the decisions this army makes every turn |
| Key units | Links to `KB/units/` pages |
| Detachments | Links to `KB/detachments/` pages |
| Learning curve | What a beginner should learn first, and the classic mistakes |
| Owned models | What is actually on the shelf, and its build state |

## Cross-linking

Every Unit and Detachment page links **back** to its Faction, and the Faction page links **forward** to them. One-way links are a lint finding.

## In scope

`necrons.md` (primary, learning army) and `space_marines.md` (secondary, contrast and opponent). See [`KB/overview.md`](../overview.md) for scope and current ownership.
