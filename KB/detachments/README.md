# KB/detachments/

One page per **detachment** - the rules package that shapes how an army is built and played.

**Type:** `detachment` · **Filenames:** lowercase `snake_case` · **Schema:** [`AGENTS.md`](../../AGENTS.md) Sec 4, Sec 6

## Suggested sections

| Section | Content |
|---------|---------|
| Detachment rule | The core mechanic, in teaching paraphrase |
| What it wants to do | The gameplan this detachment is built around |
| Enhancements | What they do and which model wants each one |
| Stratagems | Paraphrased, with the timing that actually matters |
| Units it favours | Links to `KB/units/` pages |
| Beginner fit | Is this a good first detachment, and why or why not |

## Rules discipline

Never transcribe stratagem or enhancement text verbatim - paraphrase for teaching and cite where it can be checked ([`AGENTS.md`](../../AGENTS.md) Sec 10). Detachment rules change with dataslates, so record a **retrieval date** on every claim and expect to re-verify.

## Cross-linking

Link back to the Faction page and forward to the Units the detachment is built around.

## Naming

Prefix with the faction when a name could be ambiguous across armies: `necrons_<detachment_name>.md`.
