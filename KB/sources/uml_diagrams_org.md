# uml-diagrams.org

Offline snapshots of Kirill Fakhroutdinov's uml-diagrams.org activity-family pages; a notation teaching reference, **not** a wargame rules source.

**Credit:** [About the site](https://www.uml-diagrams.org/about.html) — **authored by Kirill Fakhroutdinov**. Copyright © 2009–2026 uml-diagrams.org. All rights reserved. Third-party teaching reference; not an OMG spec dump and **not** a Kill Team rules source.

## What was ingested

Retrieved **2026-08-18**. Live HTML saved under [`reference/uml/`](../../reference/uml/README.md) (activity family + About only). The site follows OMG UML 2.5.

| Snapshot | Use in this project |
|----------|---------------------|
| UML 2.5 diagrams overview | Confirms activity diagrams sit in the **behavior** family, not class/sequence |
| Activity diagrams | Activity, partition, activity edge |
| Actions | Action as a single step; **rounded rectangle** notation |
| Controls | Initial, activity final, flow final, **decision**, merge, fork, join |
| About | Authorship and copyright line |

`reference/` is **not** project truth. The working synthesis is [[flowcharting_uml_activity]]. Shipping guide: [`docs/operations/Flowcharting.md`](../../docs/operations/Flowcharting.md).
